# SYKI 语音标注审核

这个仓库只提供审核网页，不包含语音、标注或审核结果。审核人员输入团队暗号即可使用，不需要 GitHub 账号。

网页通过独立后台读取分配任务的音频并保存审核结果。原始任务和 MP3 同时备份在私有 GitHub 仓库；在线审核结果存储在后台数据库，可在网页导出。

## 连接步骤

1. 打开 [审核网页](https://zirrtu.github.io/syki-annotation-review/)，输入团队暗号。
2. 听音频，拖动或删除已有标签；缺字时点击文字位置补字。提交后自动保存。
3. 刷新后重新输入暗号，同一浏览器可以继续未完成任务；已提交的句子不会再次分配。

请通过私下渠道分享暗号。简单暗号只适合短期试用，不能替代个人身份验证；同一浏览器的不同使用者会共用任务身份。
